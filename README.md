# Olive & Palm, Lagos shop demo

A simple, responsive one-page website concept for a fictional Lagos neighbourhood shop. This is a portfolio sample only. The shop, products, descriptions, and location references are fictional; there are no real contact details, operating claims, or business services.

## Preview locally

Open `index.html` in a browser. The page uses plain HTML and CSS with no build step or JavaScript dependency. Google Fonts are loaded from the web; system fallbacks are included.

## Files

- `index.html`: page structure, copy, and inline SVG illustrations
- `styles.css`: responsive layout, typography, and visual styling

## Demo notes

The page is intentionally a static visual concept. Product names and descriptions are illustrative only. No real shop address, phone number, opening hours, prices, or order links are provided.
